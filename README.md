# 내 앱 광장 ✦

**웹사이트(앱) 안에서 직접 앱 파일을 올리는 나만의 앱스토어**입니다.
서버 파일을 매번 수정하거나 재배포할 필요가 없습니다. 최초 배포 후에는 관리자가 앱의 **＋ 앱 올리기** 버튼에서 업로드하면 곧바로 목록에 나타납니다.

## 지원 기능

- 📱 모바일/PC 모두 사용할 수 있는 화면
- ➕ 사이트 안에서 HTML, ZIP(웹게임), APK(안드로이드 앱) 업로드
- ▶ HTML과 ZIP 웹게임은 사이트에서 바로 플레이
- ↓ APK 파일은 설치 파일을 다운로드하는 방식
- 🔍 검색, 카테고리 분류, 설명과 아이콘 추가
- 🔗 링크 공유, 관리자 로그인, 앱 삭제
- 💾 서버 디스크 또는 Railway Volume에 업로드 파일 보관
- 📲 모바일 브라우저에서 **홈 화면에 추가**하면 앱처럼 실행 (PWA)

## 내 컴퓨터에서 실행

1. Node.js 20 이상을 설치합니다.
2. 폴더에서 `npm install`을 실행합니다.
3. 관리자 비밀번호를 지정하고 실행합니다.

   macOS/Linux:
   ```bash
   ADMIN_PASSWORD="원하는-긴-비밀번호" npm start
   ```

   Windows PowerShell:
   ```powershell
   $env:ADMIN_PASSWORD="원하는-긴-비밀번호"
   npm start
   ```

4. 브라우저에서 `http://localhost:3000`으로 접속합니다.
5. 우측 위 ⚙에서 로그인한 뒤 **＋ 앱 올리기**를 누릅니다.

## Railway에 올리기 (처음 한 번만)

> 기존에 운영하는 게임 서버가 있다면 덮어쓰지 말고 **별도 Railway 서비스**를 만드세요.

1. 이 폴더의 전체 파일을 별도의 GitHub 저장소에 업로드합니다. (`node_modules`와 `storage` 폴더는 올리지 않습니다.)
2. Railway에서 **New Project → Deploy from GitHub repo**로 저장소를 연결합니다.
3. 서비스의 **Variables**에서 `ADMIN_PASSWORD`를 길고 안전한 비밀번호로 설정합니다.
4. Railway의 해당 서비스에서 **Volume**을 생성하고 마운트 경로를 **`/data`**로 지정합니다. 서버는 `/data`가 있으면 이 경로에 앱 파일을 보관합니다. 필요하면 `STORAGE_DIR=/data` 변수도 설정할 수 있습니다.
5. 서비스의 **Settings → Networking / Public Networking → Generate Domain**에서 주소를 만듭니다.
6. 생성된 주소를 휴대폰으로 열어 상단 **＋ 앱 올리기**를 누릅니다. 관리자 비밀번호로 로그인하면 앱 내에서 업로드할 수 있습니다.

**중요:** Railway에서 Volume 없이 사용하면 서비스가 재배포/재시작될 때 업로드한 앱이 사라질 수 있습니다. Volume을 연결하세요. Railway 요금제/리소스 정책에 따라 저장 가능한 크기와 요금이 달라질 수 있습니다.

## 어떤 파일을 올리나요?

- **HTML (.html):** 파일 하나로 만든 웹게임/웹앱. 업로드 즉시 웹에서 실행됩니다.
- **ZIP (.zip):** HTML, CSS, JavaScript, 그림, 소리 등 파일이 여러 개로 된 웹게임. ZIP 최상위 폴더에 `index.html` 파일이 있어야 합니다. 최상위에 폴더가 하나이고 그 안에 `index.html`이 있는 형태도 지원합니다.
- **APK (.apk):** Android 설치 파일. 다운로드할 수 있습니다. 일반 HTML 파일이나 ZIP을 APK로 자동 변환하지는 않습니다.

**iPhone 주의:** iOS에서는 APK를 설치할 수 없습니다. HTML/ZIP 웹앱은 iPhone의 브라우저에서도 실행 가능합니다(앱 코드가 모바일을 지원하는 경우).

**보안 주의:** 다운로드한 APK는 기기에서 설치 전 경고가 표시될 수 있으며, 출처가 신뢰되는 앱만 설치해야 합니다. 외부인이 마음대로 업로드하지 못하도록 관리자 비밀번호를 설정합니다. HTML/ZIP 파일은 브라우저에서 제한된 샌드박스 환경으로 실행합니다. 이 샘플은 공용 대형 앱스토어 운영에 필요한 악성코드 검사, 신고 처리, 이용약관, 백업, 개인정보 관리까지 제공하지는 않습니다.

## 제한

- 앱 파일 최대 65MB, 아이콘 최대 3MB (PNG/JPG/WEBP)
- ZIP 압축 해제 후 최대 130MB, 내부 파일 최대 500개
- `npm start`로 실행하며 Railway의 `PORT` 환경 변수를 자동 사용합니다.
- 업로드된 기록은 `STORAGE_DIR/apps.json`에 저장됩니다.

## 휴대폰에 앱처럼 설치

Railway에 배포한 HTTPS 주소를 휴대폰 Chrome 또는 Safari에서 엽니다. 브라우저 메뉴에서 **홈 화면에 추가**를 선택하면 앱 아이콘이 생기고 전체 화면 형태로 실행할 수 있습니다. 이것은 PWA 설치이며, Google Play/App Store에 등록되는 네이티브 앱은 아닙니다.
